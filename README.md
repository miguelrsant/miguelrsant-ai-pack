# AI Pack

Coleção aberta de skills reutilizáveis para desenvolvimento de software potencializado por IA, com padrões de produção, decisões arquiteturais documentadas e fluxos auditáveis de especificação a código.

![Version](https://img.shields.io/badge/Version-2.0.0-blue.svg)

## Visão Geral

O **AI Pack** é um conjunto integrado de skills de engenharia de software, cada um focado em um aspecto crítico do desenvolvimento profissional:

- **CI/CD**: pipelines com gates de qualidade, segurança e promoção de artefatos.
- **Django & REST Framework**: arquitetura de aplicações de produção, camada de serviços, APIs REST e modelos ORM.
- **Docker**: containerização segura, builds multi-stage e paridade entre ambientes de desenvolvimento e produção.
- **PostgreSQL**: modelagem segura, transactions, migrations e estratégias de evolução de banco de dados.
- **GitHub Actions**: workflows seguros, automações, artefatos e ambientes com aprovação.
- **Git Commit**: padrões de commits semânticos, organização de histórico e boas práticas de versionamento.
- **Testing**: testes automatizados, cobertura, qualidade de código e confiabilidade.
- **Open Spec Driven**: desenvolvimento orientado a especificações, contratos claros e rastreabilidade entre requisitos e implementação.
- **README Architecture Docs**: documentação arquitetural, padrões de registro de decisões e documentação técnica de projetos.
- **Skill Creator**: criação, organização e manutenção de novas skills reutilizáveis para engenharia de software assistida por IA.
